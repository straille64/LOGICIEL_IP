# V1.2 Design — Bug fixes DHCP + Rename/Move TreeView

**Date:** 2026-03-01
**Branch:** develop

---

## Objectif

Corriger deux bugs liés au DHCP et ajouter renommer/déplacer sur l'arborescence des profils.

---

## Bug 1 — Mode DHCP/Manuel non restauré au chargement d'un profil

### Cause racine

`_save_profile()` ne sauvegarde pas le mode (`dhcp`/`static`) dans le JSON.
`_load_profile()` force systématiquement `mode_var.set("static")` sans lire les données.

### Correction

**`modules/tab_config.py`**

- `_save_profile()` : ajouter `"mode": self.mode_var.get()` dans le dict `data`
- `_load_profile()` : lire `mode = data.get("mode", "static")`, appeler `self.mode_var.set(mode)` puis `self._toggle_mode()` avant de remplir les champs IP

**Format JSON profil (nouveau) :**
```json
{
  "mode": "dhcp",
  "ip": "",
  "mask": "",
  "gateway": "",
  "dns1": "",
  "dns2": ""
}
```

Rétrocompatibilité : profils sans champ `"mode"` → défaut `"static"`.

## Bug 2 — Erreur lors de l'application DHCP si l'interface est déjà en DHCP

### Cause racine

`apply_dhcp()` utilise `subprocess.run(..., check=True)`. Sur Windows, `netsh ... source=dhcp` retourne exit code 1 quand l'interface est déjà en DHCP ("Il n'y a pas d'opération à effectuer.") — état valide, pas une erreur.

### Correction

**`core/network.py`** — `apply_dhcp()`

Remplacer `check=True` par `check=False` sur les deux commandes netsh.
Rationale : exit code 1 pour `source=dhcp` = état souhaité déjà atteint. Un vrai échec (droits manquants, interface invalide) sera visible à l'utilisateur via l'absence de changement réseau.

## Feature — Renommer profils et dossiers (clic droit)

### `core/profiles.py` — nouvelles méthodes

```python
def rename(self, old_name: str, new_name: str, folder: str = "") -> None:
    """Renomme un profil JSON. Lève FileExistsError si new_name existe déjà."""

def rename_folder(self, old_name: str, new_name: str) -> None:
    """Renomme un dossier. Lève FileExistsError si new_name existe déjà."""
```

### `modules/tab_config.py` — menu clic droit enrichi

- **Sur un profil** : ajoute "Renommer" → `Querybox.get_string()` pré-rempli avec le nom actuel → `_validate_name()` → `pm.rename()` → `_refresh_tree()`
- **Sur un dossier** : ajoute "Renommer" → même flow → `pm.rename_folder()` → `_refresh_tree()`
- Si la cible existe déjà : `Messagebox.show_warning("Un profil/dossier avec ce nom existe déjà.")`

Double-clic reste inchangé (charge le profil).

## Feature — Déplacer un profil (clic droit → sous-menu)

### `core/profiles.py` — nouvelle méthode

```python
def move(self, name: str, from_folder: str, to_folder: str) -> None:
    """Déplace un profil JSON d'un dossier à un autre.
    from_folder="" ou to_folder="" = racine.
    Lève FileExistsError si la cible existe déjà."""
```

Implémentation : `shutil.move(self._path(name, from_folder), self._path(name, to_folder))`

### `modules/tab_config.py` — menu clic droit sur un profil uniquement

- Ajoute "Déplacer vers ▸" avec sous-menu construit depuis `pm.list_tree()` :
  - Profil à la racine → liste tous les dossiers disponibles
  - Profil dans un dossier → liste "Racine" + tous les autres dossiers
- Après déplacement : `_refresh_tree()`
- Si cible existe déjà : `Messagebox.show_warning(...)`
