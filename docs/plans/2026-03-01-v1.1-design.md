# V1.1 Design — Admin Indicator, Profile TreeView, MAC/Vendor Scanner

Date: 2026-03-01

## Context

V1.0 is stable (13/13 tests passing, .exe distributed). V1.1 adds three improvements:
1. Admin rights indicator + UAC restart button (global)
2. Profile management with folder TreeView sidebar (tab_config.py)
3. MAC address + Vendor columns in network scanner (tab_scanner.py)

---

## Feature 1 — Admin Rights Management

### New file: `core/admin.py`

- `is_admin() -> bool` — calls `ctypes.windll.shell32.IsUserAnAdmin()`
- `restart_as_admin()` — relaunches current process (`sys.executable` in dev,
  `sys.argv[0]` for .exe) using `ShellExecuteW` with verb `"runas"`, then `sys.exit(0)`

### Change: `main.py`

Add a fixed status bar `ttk.Frame` at the bottom of the window (below Notebook),
containing:
- `ttk.Label` showing `"[ADMIN]"` (bootstyle=SUCCESS) or `"[Utilisateur standard]"`
  (bootstyle=WARNING) — evaluated once at startup via `is_admin()`
- `ttk.Button` `"Redémarrer en Administrateur"` (bootstyle=WARNING) — visible only when
  not admin; calls `restart_as_admin()`

No threading needed — `is_admin()` is a synchronous ctypes call.

## Feature 2 — Profile TreeView with Folder Support

### Change: `core/profiles.py`

ProfileManager evolves to support subfolder structure under `profiles/`:

```
profiles/
  Clients/
    client_dupont.json
    client_martin.json
  Bureaux/
    bureau_paris.json
  profil_usine.json        ← root-level profiles still supported
```

New / modified methods:
- `save(name, data, folder="")` — writes to `profiles/{folder}/{name}.json`,
  creates subfolder if needed
- `load(name, folder="")` — reads from `profiles/{folder}/{name}.json`
- `delete(name, folder="")` — removes the file
- `list_tree() -> dict[str, list[str]]` — returns `{"": ["root_prof"], "Clients": ["p1","p2"]}`
  by walking the profiles dir one level deep
- `create_folder(folder)` — `os.makedirs`
- `delete_folder(folder)` — `shutil.rmtree` (only if empty, else warn)
- `list_profiles()` kept for backward compatibility (returns flat list, all profiles)

### Change: `modules/tab_config.py`

Layout changes from stacked LabelFrames to `ttk.PanedWindow(orient=HORIZONTAL)`:

**Left pane (~200px):** `ttk.Treeview` (show="tree", selectmode="browse")
- Populated by `pm.list_tree()` at startup and after any profile change
- Folders = top-level nodes (iid=`"folder::{name}"`, text=`"📁 {name}"`)
- Profiles = child nodes (iid=`"profile::{folder}::{name}"`, text=`"📄 {name}"`)
- Root profiles = children of a hidden root or top-level nodes
- **Double-click** on a profile node → load into form (replaces Charger button)
- **Right-click** context menu on tree:
  - On folder: *Renommer*, *Supprimer le dossier*
  - On profile: *Supprimer le profil*
  - On empty area: *Nouveau dossier*
- Below the tree: `ttk.Button` "Sauvegarder ici" → saves current form data to selected
  folder (or root if none selected), prompts for name via `Querybox.get_string()`

**Right pane:** existing IP config + quick tools sections, unchanged in behavior.

The existing "Profils" LabelFrame (Combobox + buttons) is removed and replaced by the
TreeView sidebar.

## Feature 3 — MAC Address + Vendor in Scanner

### Dependency

Add `mac-vendor-lookup>=0.1.12` to `requirements.txt`.
Use `from mac_vendor_lookup import MacLookup` — requires one-time `MacLookup().update_vendors()`
on first run or bundle the vendors file. The package ships with a built-in vendor DB,
so no update call is needed in normal use.

### Change: `core/scanner.py`

- `get_mac_from_arp(ip: str) -> str` — runs `arp -a {ip}` (shell=True, encoding=cp850),
  parses output with regex `r'([0-9a-f]{2}[:-]){5}[0-9a-f]{2}'` (case-insensitive),
  returns first match normalized as `AA:BB:CC:DD:EE:FF` or `""` if not found
- `get_vendor(mac: str) -> str` — calls `MacLookup().lookup(mac)`, returns vendor string
  or `""` on `KeyError`/`VendorNotFoundError`
- `ping_host()` return dict gains `"mac": ""` and `"vendor": ""` keys (filled as empty
  during ping phase)
- `scan_range()` after collecting all ping results: for each alive host, calls
  `get_mac_from_arp(ip)` and `get_vendor(mac)` sequentially (no extra threading needed
  since ARP reads are fast)

### Change: `modules/tab_scanner.py`

- Tableview `coldata` gains two columns: `"Adresse MAC"` (width=140, stretch=False)
  and `"Fabricant"` (stretch=True)
- `_populate_table()` passes `[r["ip"], r["hostname"], status, rtt, r["mac"], r["vendor"]]`
- `_export_csv()` adds `mac` and `vendor` to fieldnames
